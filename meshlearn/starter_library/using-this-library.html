How to use this library

Everything here is stored on this phone's memory card. You do not need the internet or mobile data to read it.

Finding things

Use the search box on the Library page. Type a word from the title, like "fractions" or "Wikipedia".

Big encyclopedias

Files ending in .zim are whole encyclopedias, such as Wikipedia. If your teacher set up the Kiwix reader, the link opens the encyclopedia in your browser. Otherwise, open the file with the Kiwix app.

Books

Files ending in .epub are e-books. Most phones can open them with a reading app. Files ending in .txt open in any browser.

Sharing the connection

Many students can use the library at the same time. If pages load slowly, take turns downloading large files.
